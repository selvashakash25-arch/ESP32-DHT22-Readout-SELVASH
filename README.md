# ESP32 DHT22 Readout

## Author
SELVASH

## Description
This project measures temperature and humidity using a DHT22 sensor connected to an ESP32.

The readings are displayed in the Serial Monitor every 2 seconds.

## Components
- ESP32 DevKit
- DHT22 sensor

## Connections

| DHT22 | ESP32 |
|---|---|
| VCC | 3.3V |
| DATA | GPIO 4 |
| GND | GND |

## Features
- Temperature measurement
- Humidity measurement
- Serial Monitor output
- Readings updated every 2 seconds
- Wokwi simulation
